🌟 Elderfy - Stripe Payment Setup Guide

⏱️ Setup Time: 5 minutes
💰 Cost: Free (2.9% + $0.30 per transaction)
📱 Mobile Friendly: Yes! Can setup from your phone

🚀 Quick Setup (Test Mode)

Step 1: Create Stripe Account

  1. Go to https://dashboard.stripe.com/register
  2. Sign up with your email address
  3. Enter basic business information
  4. Skip detailed onboarding for now (can complete later)

Step 2: Get Your Test API Keys

  1. Log into Stripe Dashboard
  2. Go to https://dashboard.stripe.com/test/apikeys
  3. Make sure you're in Test mode (toggle in top right)
  4. Copy both keys:
    • Publishable key: Starts with pk_test_
    • Secret key: Click "Reveal test key" - starts with sk_test_

Step 3: Add Keys to Vercel

  1. Open https://vercel.com/dashboard
  2. Click on your elderfy project
  3. Go to Settings → Environment Variables
  4. Add Variable #1:
Name Value
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY Your pk_test_... key
  1. Click Save
  2. Add Variable #2:
Name Value
STRIPE_SECRET_KEY Your sk_test_... key
  1. Click Save

Step 4: Redeploy Your Site

  1. Go to Deployments tab in Vercel
  2. Click the three dots (...) on the latest deployment
  3. Click Redeploy
  4. Wait 2-3 minutes for deployment to complete

✅ You're Done!

Your site now accepts test payments. Try it out!

💸 Payment Flow

Donations (One-Time Payments)

  1. User clicks amount button ($5, $10, $25, $50) or enters custom amount
  2. Redirected to Stripe Checkout (secure Stripe-hosted page)
  3. User enters payment details
  4. On success → redirected to /success page
  5. On cancel → redirected back to elder profile

Subscriptions (Recurring Monthly)

  1. User clicks "Subscribe" button
  2. Creates $10/month recurring subscription
  3. Same checkout flow as donations
  4. Auto-charges every month until cancelled
  5. User can manage/cancel in Stripe Customer Portal

🏦 Going Live (Real Payments)

⚠️ Important: Only do this when you're ready to accept real money!

Step 1: Complete Stripe Onboarding

  1. Go to https://dashboard.stripe.com/account/onboarding
  2. Provide business details:
    • Business type and address
    • Tax information
    • Bank account for payouts
  3. Complete identity verification (ID/passport upload)
  4. Wait for Stripe approval (usually instant, can take 1-2 days)

Step 2: Get Live API Keys

  1. In Stripe Dashboard, toggle from Test mode to Live mode (top right)
  2. Go to https://dashboard.stripe.com/apikeys
  3. Copy both LIVE keys:
    • Publishable key: pk_live_...
    • Secret key: sk_live_...

Step 3: Update Vercel Environment Variables

  1. Go to Vercel Dashboard → elderfy → Settings → Environment Variables
  2. Edit NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
    • Replace test key with live pk_live_... key
  3. Edit STRIPE_SECRET_KEY
    • Replace test key with live sk_live_... key
  4. Save both changes

Step 4: Redeploy

  1. Go to Deployments → Click (...) → Redeploy
  2. Your site now accepts REAL payments!

⚙️ Customization

Change Subscription Price

  1. Edit file: app/api/create-subscription/route.ts
  2. Find line 23: unit_amount: 1000
  3. Change amount:
    • 500 = $5.00/month
    • 1000 = $10.00/month (current)
    • 2500 = $25.00/month
  4. Commit and push changes

🔔 Webhooks (Optional)

Webhooks notify your app when payments succeed. Useful for:

  • Saving payment records to database
  • Sending thank-you emails
  • Updating user subscriptions

Setup Webhooks

  1. Go to https://dashboard.stripe.com/webhooks
  2. Click Add endpoint
  3. Enter: https://your-domain.vercel.app/api/webhooks
  4. Select events to listen for:
    • checkout.session.completed
    • customer.subscription.deleted
  5. Copy webhook signing secret
  6. Add to Vercel as: STRIPE_WEBHOOK_SECRET

🆘 Troubleshooting

Problem Solution
"API key invalid" Check keys in Vercel match Stripe Dashboard. Redeploy after changes.
Buttons don't work Ensure environment variables are set. Check browser console for errors.
No redirect to checkout Verify publishable key starts with NEXT_PUBLIC_ in Vercel.
Test payments not showing Make sure you're in Test mode in Stripe Dashboard.
